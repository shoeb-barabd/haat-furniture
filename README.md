# 🛋️ HAAT FURNITURE LIMITED — Full-Stack E-Commerce Solution

Official 100% Solid Chittagong Segun Wood E-Commerce Application with Next.js Storefront & Laravel API Backend.

## 🚀 Live Demo & Production Server
- **Live Website**: [https://haat.barabdonline.com](https://haat.barabdonline.com)
- **All 128 Products Catalog**: [https://haat.barabdonline.com/products](https://haat.barabdonline.com/products)
- **Express Checkout**: [https://haat.barabdonline.com/checkout](https://haat.barabdonline.com/checkout)
- **Admin Dashboard**: [https://haat.barabdonline.com/admin](https://haat.barabdonline.com/admin)

## 🛠️ Technology Stack
- **Frontend**: Next.js 16 (React 19, TailwindCSS, Motion Animations, Lucide Icons)
- **Backend**: Laravel 11 REST API (SQLite Database)
- **Deployment**: Proxmox VE VM 109, Nginx Reverse Proxy, PM2 Process Manager, Cloudflare Tunnel (HTTPS)

## 📦 Features
- 128 Authentic Chittagong Segun wood furniture products.
- Interactive Category Sliders & Soft Pastel Creations section.
- Staggered Slow-Motion Entrance Animations on Scroll.
- Real-Time Shopping Cart & Checkout with Dhaka vs Outside Dhaka shipping logic.
- Official WhatsApp Integration.
